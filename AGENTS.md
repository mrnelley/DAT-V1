# Frontend work

- Use the shared brand tokens and local fonts in `public/compass/brand.css` for new frontend work. Keep the hosted UI and `src/theme/index.js` aligned.
- Use approved logo assets from `src/theme/brandAssets.js` unchanged, with clear space and a suitable background. Decorative illustrations are not replacement logos.
- Keep interface copy concise and operational. Do not add explanations of implementation or visibility rules unless they help the user make a decision.
- The user's HDC brand guide is proprietary and remains outside this repository. Never copy the PDF, extracted pages, reference imagery, or a transcript/summary of it into the project, build output, or source control. Only application styling and public, licensed font assets belong here.
