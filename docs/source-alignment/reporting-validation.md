## Operating Language Alignment

The overview frames Compass as a centralized operational accountability system, not a task manager. The app language now reflects that framing in the Learn dictionary and reporting map:

- Enterprise visibility, alignment, ownership, and execution discipline.
- Behavior-driven accountability embedded into leadership rhythms.
- Strategic plan, Enterprise Priorities, department workplans, Departmental Priorities, Weekly Priorities, Action Items, stucks, and calendar commitments as one connected chain.
- Dashboards as reporting and accountability surfaces, not generic editing or task-list screens.

## Week-Over-Week Validation

The OLT action tracker contains weekly priority tabs from 5-11-26 through 8-10-26. The app weekly config now mirrors those tabs and sets the current week to 7-13-26 for the current operating date of July 14, 2026.

Weekly Tracker language now follows the workbook structure:

- #1 Most Important Priority, #2 Priority, and #3 Priority.
- Enterprise Priority or Departmental Priority alignment.
- Desired result.
- Risk/support needed with specific people and support.
- Action Items underneath the weekly commitment.

## Workplan Template Validation

The workplan page now supports the missing source-template fields at the Department Objective level:

- Org Priority
- Key Performance Indicator (KPI)
- Year End Target
- Start Date
- End Date
- Current Status
- Percent progress
- Progress and Challenges
- Last Update Date
- Lead Person
- Project Plan Complete?
- Project Plan Link

These fields are optional so departments can draft quickly, then fill in the full template-level reporting detail as the plan matures.
