# Compass documentation

Use this folder as the maintained operating record for the application.

Hosted development releases: [Metric entry](database/hosted-metric-release.md) and [Weekly accountability](database/hosted-weekly-release.md).

Latest confirmed decisions: [Access and development launch contract](mvp/access-and-launch-contract.md).

Current application: [Rollups and Admin handoff](mvp/rollups-admin-handoff.md). The planning catalog and Dictionary are in the root application's Learn hub. Earlier metric proposals are superseded by [confirmed clarifications](mvp/confirmed-metric-clarifications.md).

Administration: [Command center, user creation and deployment](database/admin-command-center.md).

- `architecture/`: repository, release, and system decisions
- `database/`: persistence plans and schema implementation notes
- `mvp/`: current scope, estimates, dependencies, and validation gates
- `product/`: role stories and expected application behavior
- `source-alignment/`: checks against the original workplan and reporting materials

Start with [Repository and release workflow](architecture/repository-and-release-workflow.md), then use the [schema and component map](mvp/schema-and-component-map.md), [MVP implementation index](mvp/implementation-index.md), and [database validation gate](mvp/database-validation.md) before applying schema changes.
